# Video Review Gate Skill

Allows autonomous agents to present decisions, rough cuts, and master renders to the user via Telegram interactive buttons, backed by external Cloudflare streaming links.

## Principles

1. **No Chat Spam**: Do not output endless JSON or logs to Telegram chat.
2. **Interactive Decisions**: Use inline keyboard buttons (`[✅ Approve]`, `[🔄 Reroll]`, `[✂️ Revise]`).
3. **Instant Responsiveness (<50ms)**: Always acknowledge button taps immediately via `answerCallbackQuery` so mobile clients never spin or freeze.
4. **Milestone Telemetry**: Post multi-stage development cards (Audio Analysis, Storyboard/Typography, Preview Frame 0 `sendPhoto`).
5. **Native Playable Video Delivery**: Never deliver raw `.tsrct` project files or silent video. Always mux master FLAC audio and deliver final playable `.mp4` directly into chat using `sendVideo`.
6. **Cloudflare Distribution**: Deliver video previews and project archives via ephemeral `trycloudflare.com` links generated by `secure-share`.

## Python Usage

```python
from src.telegram.gateway import TelegramGateway

gateway = TelegramGateway()

# 1. Deliver preview photo frame
gateway.send_photo("preview.png", caption="📸 Preview Frame 00:00.000")

# 2. Deliver playable MP4 with master audio mux
gateway.send_video(
    "render_final.mp4",
    caption="🎬 VØIDRIDE // CHROMA MORGUE",
    buttons=[[{"text": "⚡ Stream via Cloudflare", "url": "https://*.trycloudflare.com"}]]
)
```
