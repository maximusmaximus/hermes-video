# Hermes Video 🎬⚡

**Autonomous video editing and motion graphics engine powered by Hermes Agent and Tesseract by Mirage.**

Connects autonomous AI video direction directly with the **VØIDRIDE** music catalog, local GPU-accelerated video rendering via **Tesseract**, strict **Venice AI** daily inference budget enforcement, and **Telegram / Cloudflare** human-in-the-loop review gates.

---

## Key Features

- **Local Tesseract Creative Suite**: Renders non-destructive video edits, native vector motion graphics, and kinetic typography locally on Windows/macOS using the official [Tesseract by Mirage](https://github.com/mirage-hq/Tesseract) engine.
- **Deep Music Catalog Integration**: Discovers and indexes 19+ albums, master FLACs, stems (drums, bass, synths, ambience), BPMs, and keys generated by the `hermes-music` producer agent (`D:\music`).
- **Strict Daily Inference Budgeting**:
  - **$5.00 / day** total ceiling on Venice AI inference.
  - **$1.00 / day** hard cap on the Controller Hermes Agent.
  - Persistent SQLite ledger with rolling 24-hour pre-flight budget blocking.
- **Standardized Video Practices**: Enforces audio-first transient alignment, phrase-based pacing, cubic-bezier easing, eyeline continuity, and 6-vector scene prompt schemas.
- **Sub-50ms Telegram Responsiveness**: Multi-threaded background daemon (`ThreadPoolExecutor`) ensures zero UI freezes and instant haptic toast feedback via `answerCallbackQuery`.
- **4-Phase Development Telemetry**: Real-time production milestone notifications sent to Telegram (Audio transient analysis, Kinetic typography storyboard, High-res preview frame photo, and Live in-place progress bar).
- **Master Audio Muxing & Native Video Delivery**: Auto-muxes master 24-bit/48kHz FLAC into rendered MP4 via FFmpeg and delivers playable videos directly into Telegram (`sendVideo`) with waveform and sound controls.
- **Cloudflare Tunnel Distribution**: Automatically packages render previews via `secure-share` (`cloudflared`) and embeds direct `trycloudflare.com` links for instant mobile streaming.
- **Modular & Extensible**: Pluggable `BaseVideoEngine` interface designed to wire future local or cloud video generators (ComfyUI, Runway, Kling, Luma) seamlessly.

---

## System Requirements

- **Operating System**: 64-bit Windows 10/11 (`AMD64`) or macOS (Apple Silicon `arm64` / Intel `x86_64`).
- **Tesseract CLI**: Pinned version `0.1.0` (installed locally at `%LOCALAPPDATA%\Tesseract\bin\tsrct.cmd`).
- **Python**: 3.8+ (supports Python 3.11).
- **Network**: Internet access for Venice AI and Telegram Bot API.

## Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/maximusmaximus/hermes-video.git
cd hermes-video
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure Environment
Copy `config/.env.example` to `.env` and provide your credentials:
```bash
cp config/.env.example .env
```

Set your keys:
- `TELEGRAM_BOT_TOKEN`: Your Telegram Bot API token.
- `TELEGRAM_CHAT_ID`: Your chat ID (default: `8293122782`).
- `VENICE_CONTROLLER_KEY`: Venice key for Controller agent ($1/day limit).
- `VENICE_WORKER_KEY`: Venice key for worker/generative tasks ($4/day limit).

### 4. Run the Workflow Orchestrator
```bash
# Run with a specific album from the music catalog
python -m src.workflow --track "chroma-morgue" --aspect-ratio "16:9"

# Query the music catalog
python -m src.catalog.query --list-albums
python -m src.catalog.query --album "chroma-morgue"

# Dry-run mode (tests pipeline without spending budget or Telegram calls)
python -m src.workflow --dry-run
```
